Prueba de carnets

Pase un carnet para ver de quién es. No marca asistencia: sirve solo para comprobar que los carnets se leen bien.

Pase un carnet por el lector, o muestre a la cámara el código QR (el cuadrado) del carnet
  • Todavía no ha probado ningún carnet.

Con la cámara, use el código QR (el cuadrado): se lee mucho mejor que el código de barras, que es para el lector USB. Se muestra lo mismo que verá el trabajador al marcar su entrada, incluido el saludo. Si un carnet dice "no se leyó bien", páselo otra vez; si dice "no está registrado", se reemplazó por uno nuevo o falta asignarlo en Talento humano › Trabajadores.
